What is the 8-Puzzle?

A 3×3 board holds eight numbered tiles and one empty space. A move slides an adjacent tile into the blank. Starting from a scrambled arrangement, the goal is to reach a target arrangement (usually 1–8 in order, blank last) using as few moves as possible.

Why it matters

It is a textbook search problem: 9!/2 = 181,440 reachable states, branching factor 2–4, and optimal solutions of up to 31 moves. Exactly half of all arrangements are unsolvable, decided by the parity of inversions.

Uniform Cost Search (UCS)

UCS is an uninformed search algorithm that always expands the frontier node with the lowest accumulated path cost g(n). It is Dijkstra's algorithm applied to an implicit graph, and it needs no heuristic. In the 8-puzzle every move costs 1, so UCS expands states level by level and behaves like Breadth-First Search, while still being correct for arbitrary positive step costs.

Working Principle

  1. Put the start node in a priority queue keyed by g(n) = 0.
  2. Pop the cheapest node. If it is the goal, stop; the path is optimal.
  3. Otherwise expand it: slide the blank to each legal neighbour to create successors with g = g(parent) + 1.
  4. Skip successors already in the frontier or explored set; push the new ones.
  5. Repeat until the goal is popped or the queue is empty (no solution).

Complexity & Properties

  • Time: O(b1+⌊C*/ε⌋); with unit costs O(bd)
  • Space: O(b1+⌊C*/ε⌋); all generated nodes are stored
  • Complete: Yes, if b is finite and every step cost ≥ ε > 0
  • Optimal: Yes; nodes are expanded in order of increasing path cost
  • 8-puzzle: b ≈ 2.67 average, at most 181,440 states, max depth 31

Advantages

  • Guarantees the cheapest solution
  • Needs no domain knowledge or heuristic
  • Handles non-uniform step costs
  • Complete on finite state spaces

Limitations

  • Explores in every direction, including away from the goal
  • Memory grows exponentially with solution cost
  • Slower than A* with an admissible heuristic
  • Needs a duplicate check to avoid re-exploring states
